# CHANGELOG

## v1.4.1 [2026-11-22]
- Added headroom, crossfeed, DAC filter and gain options for Qudelix devices.
- Fixed bugs and improved stability.

## v1.4.0 [2026-11-21]
- Added separate left and right channel EQ editing on devices that support it.
- Added a presets sheet to create, rename and delete the presets stored on the device.
- Added an EQ picker for devices with more than one EQ, such as Qudelix's headphone EQ.
- Added support for Topping devices, and more device control options.
- Fixed a dialog opened over a sheet not dimming the sheet beneath it.

## v1.3.5 [2026-11-12]
- Improved compatibility with Walkplay devices.

## v1.3.4 [2026-11-11]
- Improved compatibility with Moondrop devices.
- Fixed an issue where an EQ could be applied twice, when linked with modernGraphTool from the same device.

## v1.3.3 [2026-11-09]
- Improved compatibility with Kiwi Ears devices.

## v1.3.2 [2026-11-03]
- Improved compatibility with FiiO devices.

## v1.3.1 [2026-11-01]
- Improved compatibility with TANCHJIM and Walkplay-based devices.

## v1.3.0 [2026-10-31]
- Added device control features with gain, filter, usb mode and more.
- Added broader support for Fosi Audio, NICEHCK, and TANCHJIM devices.
- Fixed several bugs and adjusted the UI for better usability.

## v1.2.3 [2026-10-25]
